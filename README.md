# **Калькулятор**
## Калькулятор может складывать, вычитать и умножать
## Создание функции калькулятора и передаём туда ссылки
```cpp 
void calculator(int& a,int& b,int& c,int& s, char& p )
{
```
## Проверка команды
```cpp
    if (p == '+'){
        s = a + b + c;
    }
    else if (p == '-'){
        s = a - b - c;
    }
    else if (p == '*'){
        s = a * b * c;
    }
```
## Ошибка, если не введена правильно команда
```cpp
    else{
        cout << "Такой команды нет" << endl;
    }
```

## Создаём переменные
```cpp
    int a;
    int s = 0;
    int b;
    int c;
    char p;
```
## Вводим переменные и команду с клавиатуры
```cpp
cout << "Введите три числа "<< endl;
cin >> a >> b >> c;  
cout << "Введите команду(+,-,*) " << endl;
cin >> p ;
```
## Вызываем функцию и выводим её
```cpp
calculator(a,b,c,s,p);
cout << s;
```
